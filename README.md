# ditto-chaos
## Sample application
We use Eclipse Ditto: https://github.com/eclipse-ditto/ditto (EPL-2.0)

## How to run Ditto
git clone https://github.com/eclipse-ditto/ditto.git
cd ditto/deployment/docker
docker compose up -d
Open http://localhost:8080/ui/  (login: ditto / ditto)
